# 2026 新生资料包

这一页根据公开腾讯文档《这是一个关于安徽科技工程大学的介绍文档（针对 2026 新生同学）》整理。原文由学长 Mr.Leo 制作，文档内标注“未经授权不得搬运、商用”，所以本站只做入口导航、摘要说明和使用建议，不全文搬运。

<span class="source-badge experience">经验参考</span> 这些资料很适合帮助新生快速找到学长整理的信息，但涉及校区分配、专业计划、报到流程、录取政策等关键事项时，仍要回到学校官网、招生就业处和迎新网核对。

## 使用建议

- 把腾讯文档当作“学长整理的导航页”，适合查找图片、群聊、美食和经验资料。
- 涉及报到时间、缴费、录取、专业计划、校区分配、宿舍安排时，优先看学校官方页面。
- 群聊和经验帖里的联系方式、收费信息、代办信息要谨慎核验，不要轻易转账或提交个人隐私。
- 如果你后续要把腾讯文档里的某个子文档正式写进本站正文，建议先确认作者授权或只写摘要并保留链接。
