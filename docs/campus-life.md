# 校园生活

这一页整理新生最关心的吃、住、洗浴、开水、洗衣、校园卡和网络。宿舍楼栋、床位、收费、热水供应等会随校区和年份变化，务必以入学当年安排为准。

## 食堂与餐饮

<span class="source-badge">官方确认</span> 迎新网饮食服务页显示，学校三个校区共有多家餐饮企业在校经营，保障约 2 万名师生餐饮服务。

| 校区 | 官方公开信息 |
| --- | --- |
| 凤阳校区 | 东区一楼和二楼、西区食堂一楼和二楼，可供 10000 多名师生就餐；每餐品种不少于 40 个，设风味窗口。 |
| 龙湖校区 | 现有 3 个校园餐厅，可保障约 10000 名师生就餐、开水与洗浴服务。 |
| 滁州校区 | 北区百味园餐厅一层，南区丰味园餐厅一、二、三层；支持一卡通、人脸识别和校园卡支付。 |

官方页列出的服务时间为：早 6:00-8:30，中午 11:00-13:00，晚 17:00-20:00。实际窗口时间以食堂现场和后勤通知为准。

## 宿舍、洗浴与洗衣

<span class="source-badge">官方确认</span> 迎新网饮食服务页公开了生活保障设施：

- 公共楼宇，包括宿舍楼、教学楼、实验楼、办公楼等，安装开水机。
- 龙湖校区宿舍楼层建有洗浴间。
- 凤阳校区部分宿舍楼层建有洗浴间，校园超市上方另设公共洗浴中心。
- 滁州校区为独立卫浴，宿舍实现热水供应，并配套洗衣、烘干、吹风等设备。
- 洗衣机进入宿舍楼层。

## 校园一卡通

校园一卡通页面说明，学校已实现校园卡与手机绑定，可通过微信“虚拟卡包”在校内食堂就餐、超市购物、付费洗浴、学生购电、宿舍楼宇与图书馆门禁等场景使用，也可进行挂失、余额查询、账单查询。

新生常用操作：

1. 领取或激活微信虚拟卡包。
2. 进入虚拟卡包查看余额、账单和行业码。
3. 通过生活缴费入口给宿舍电费充值。
4. 实体卡遗失时先自助挂失，再联系校园卡中心补办。

## 网络、图书馆与医疗

迎新网的“学习生活”栏目提供网络服务、图书馆、保险医疗服务等入口。由于这些页面可能包含登录、校内网络或动态通知，建议入校前收藏入口，入校后按学院通知办理。
