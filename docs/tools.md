## 交通备忘

| 场景 | 建议 |
| --- | --- |
| 到龙湖校区 | 优先查蚌埠南站、蚌埠站到校公交或迎新车。 |
| 到凤阳校区 | 优先确认蚌埠站/蚌埠南站是否有迎新车；平时可看凤阳汽车站与凤阳城区公交。 |
| 到滁州校区 | 优先确认滁州站、全椒站迎新车；平时看 103、107、111 路等公交。 |
| 飞机到达 | 官方交通页提到南京禄口国际机场、合肥新桥国际机场可转高铁或汽车。 |

## 信息防骗提醒

- 只在学校官方域名、录取通知书标注入口或学院通知入口办理缴费、报到和账号激活。
- 不轻信陌生群里“内部宿舍分配”“提前缴费”“代办校园卡”。
- 需要贷款或绿色通道时，先看迎新网“奖助贷学”和学院通知。
- 第三方经验帖可参考准备清单，不可替代学校通知。
