# 新生报到

这一页按“录取后到进校当天”的顺序整理。具体日期、批次、系统开放时间、材料要求每年会变化，请以录取通知书、迎新网和招生就业处公告为准。

<span class="source-badge">官方确认</span> 流程入口来自安徽科技工程大学新生报到网，采集于 2026-06-01。

## 报到前清单

<ul class="check-list">
  <li>确认录取通知书、身份证、档案、党团组织关系等材料要求。</li>
  <li>关注“安科之生”“安科学工”等官方渠道，查看当年报到动态。</li>
  <li>在迎新系统或学校要求的平台完成预报到、信息核验、线上教育等任务。</li>
  <li>确认自己所在校区，不同校区到站、公交、自驾路线不同。</li>
  <li>提前规划到站时间，报到日接站安排以当年迎新通知为准。</li>
</ul>

## 迎新网能查什么

新生报到网公开入口包括：

| 分类 | 内容 |
| --- | --- |
| 网上报到 | 蚌埠校区、凤阳校区、滁州校区入口 |
| 报到指南 | 报到流程、交通路线、组织关系、户口档案、缴费须知、新生军训 |
| 奖助贷学 | 助学贷款、绿色通道、奖学金介绍、勤工助学 |
| 了解安科 | 学校简介、院系导航、地理位置、宣传片、学生管理制度 |
| 学习生活 | 部门电话、保险医疗、图书馆、网络服务、校园一卡通、饮食服务 |

## 到校交通

### 报到日接站

迎新交通页说明，新生报到当天学校会在蚌埠火车站、蚌埠南站，以及滁州站、全椒站设置新生接待点。接站是否开放、开放时间和乘车点请以当年迎新公告为准。

### 龙湖校区

地址：安徽省蚌埠市龙子湖区大学城黄山大道 1501 号。  
高铁或动车到蚌埠南站后，可关注迎新专车，也可参考公交 126 路、128 路转 115 路、117 路、207 路等路线到校。普通火车到蚌埠站后，可关注迎新专车或乘 115 路、117 路、207 路到校。

### 凤阳校区

地址：安徽省滁州市凤阳县东华路 9 号。  
乘高铁、动车或普通火车的新生，迎新交通页推荐在蚌埠南站或蚌埠站下车后转乘学校迎新车辆。平时可结合凤阳汽车站、凤阳城区公交和蚌埠方向班车规划。

### 滁州校区

地址：安徽省滁州市南谯区文慧路 999 号。  
乘高铁的新生，可关注滁州站、全椒站与迎新车辆安排。平时可参考滁州公交 103 路、107 路、111 路等线路。

## 报到当天建议

- 先看清校区，再看路线，避免“安徽科技工程大学”三个校区混淆。
- 重要证件和录取材料随身携带，不要放在托运行李最深处。
- 遇到“代办校园卡、代办贷款、代收费”等信息，先向学校官方老师或迎新点确认。
- 家长同行时，提前确认校内交通、停车和宿舍区域安排。
